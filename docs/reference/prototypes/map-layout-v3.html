A안 수정: 가운데 허브에 다 모으고, 스폰도 가운데

약 26m × 26m · 정원 50명 · 위에서 내려다본 배치도 (네모 = 기계, 점 = 사람, 초록 점선 = 스폰)

가운데 허브 (10m × 10m)

· 한가운데 4면 전광판 탑, 그 둘레가 스폰 지점 → 접속하면 전광판 앞에서 시작

· 대각선 네 귀퉁이에 균형 있게: 코인 교환소 2곳(서로 마주 봄) · 도감 NPC · 이벤트(오늘의 기계·피버 타임)

· 허브에서 위·왼쪽·오른쪽·아래 네 갈래 길이 각 구역으로 이어짐

구역 셋이 허브를 둘러쌈

· 큰인형 = 위쪽 띠 (기계가 커서 가장 넓게) · 미니 = 왼쪽 ㄴ자 · 피규어 = 오른쪽 ㄴ자

· 입구는 없앰 (스폰이 가운데라서)
